Semantic Segmentation of Wildlife Images using U-Net

As part of my internship in the Department of Geography, Environment, and Geomatics at the University of Ottawa, I developed a geospatial deep learning pipeline using the U-Net architecture for pixel-wise semantic segmentation of squirrel images. The model focuses on separating squirrel regions from complex natural backgrounds while accounting for variations in color (black and brown squirrels).

View Project on GitHub

Key Highlights

  • Dataset Preparation & Preprocessing
    • Collected and curated 500 wildlife images for training and evaluation.
    • Generated pixel-level segmentation masks using OpenCV-based masking techniques.
    • Applied preprocessing steps including resizing, normalization, and data augmentation to improve model robustness.
  • Deep Learning Model Development
    • Implemented a U-Net architecture for semantic segmentation tasks.
    • Designed the model to perform pixel-wise separation of squirrel foreground from background environments.
  • Training & Evaluation
    • Used Binary Cross-Entropy loss function for optimization.
    • Evaluated model performance using Intersection over Union (IoU) as the primary metric.
    • Analyzed probability-based output masks (0–1 range) to assess prediction confidence.

Results

  • Intersection over Union (IoU): 0.79, indicating strong overlap between predicted and ground truth segmentation masks.
  • Model Performance: Successfully learned to separate squirrel foreground regions from complex natural backgrounds.
  • Output Quality: Produced stable probability maps with clear pixel-level distinction between foreground and background.
