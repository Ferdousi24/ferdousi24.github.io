GIS Automation: ArcPy-Based Map Layout Workflow

Project Type: Coding Digital Earth Course-University of Ottawa| GIS Automation Workflow

Python ArcPy ArcGIS Pro GIS Automation Cartography Spatial Visualization

Overview:
Developed as part of an applied Digital Earth programming laboratory, this project demonstrates foundational GIS automation skills using Python and ArcPy to streamline map layout production workflows in ArcGIS Pro. The workflow focused on automating repetitive cartographic tasks including layout element modification, positioning, and standardized export generation for reproducible geospatial reporting outputs.

Project Objectives

  • Automate GIS map layout customization using Python.
  • Standardize cartographic elements across map outputs.
  • Reduce repetitive manual editing tasks in ArcGIS Pro.
  • Improve reproducibility of spatial reporting workflows.

Tools and Technologies

  • Programming Language: Python
  • GIS Platform: ArcGIS Pro
  • Library: ArcPy (`arcpy.mp`)
  • Workflow Focus: GIS Automation & Cartographic Layout Scripting

Workflow & Key Highlights

  • ArcGIS Project Access: Loaded and accessed ArcGIS Pro project files (.aprx) programmatically using ArcPy.
  • Layout Element Manipulation: Queried and modified map layout elements dynamically, including map title updates, north arrow repositioning, and scale bar placement using coordinate-based controls.
  • Automated Cartographic Workflow: Applied Python automation techniques to reduce repetitive manual cartographic editing steps and standardize map layout production.
  • Map Export Generation: Exported finalized layouts to PNG format for visualization, reporting, and documentation workflows.
