GeoAI Workflow for AI-Assisted Mapping & Building Extraction

YouthMappers – Introduction to GeoAI Course Project

Project Overview

This project explores an end-to-end GeoAI workflow combining OpenStreetMap mapping, QGIS-based AI tools, Vision-Language Models (VLMs), and Python-based geospatial image processing. The objective was to understand modern GeoAI techniques for building extraction and spatial feature analysis using both AI-driven and rule-based methods.

GIS & Mapping

  • QGIS
  • OpenStreetMap (OSM)
  • RapiD Editor
  • JOSM

GeoAI / AI Tools

  • Segment Anything Model (SAM) plugins in QGIS
  • Vision-Language Models (VLMs) – “Talking to Your Map”

Programming

  • Python
  • Raster Processing
  • Image Thresholding
  • Morphological Operations
  • Raster-to-Vector Conversion

Workflow Overview

OpenStreetMap Mapping → QGIS GeoAI (SAM + VLMs) → Python Rule-Based Processing → Building Extraction → Validation

1. AI-Assisted Mapping (OpenStreetMap)

Explored collaborative mapping workflows using RapiD and OpenStreetMap for spatial feature creation and editing.

  • AI-assisted feature mapping using RapiD
  • OpenStreetMap editing and digitization
  • Introductory exposure to mapping workflows
Image: RapiD Mapping Interface Screenshot

2. GeoAI in QGIS (SAM + VLMs)

Applied GeoAI tools in QGIS for automated building extraction and interactive map interpretation.

  • SAM-based building segmentation from satellite imagery
  • Extraction of building footprints using AI plugins
  • Comparison of AI output with manual interpretation
  • Explored Vision-Language Models (VLMs)”
Images: QGIS building extraction results / VLM outputs

3. Python-Based Rule Processing (Experimental)

Developed a rule-based geospatial image processing workflow to understand foundational image analysis techniques.

  • Brightness-based thresholding for feature detection
  • Masking for isolating spatial objects
  • Morphological operations for noise reduction
  • Raster-to-vector conversion for building footprints
